# 关于《阅游 V1.1.0》软件独创性说明

申请人：胡传龙

软件名称：阅游 V1.1.0

## 一、软件性质

《阅游 V1.1.0》是一款融合"沉浸式小说听读"与"2048 益智游戏"两大核心场景的移动端原创软件。客户端采用 Flutter 3.x / Dart 3.x 框架开发，服务端采用 Go 1.21+ 实现，整体架构遵循 Feature-Driven Clean Architecture 设计范式，由申请人独立完成全部产品设计、技术选型、架构搭建、编码实现与测试验收。

## 二、独创性技术要点

### 1. 独创得分算法：全盘求和计分法

市面常见 2048 实现普遍采用"合并方块数值累加"的计分方式，本软件首创**全盘求和计分法**：每次移动后即刻对 4×4 棋盘上所有非空方块的数值求和，作为当前得分；并维护连续合并的 Combo 计数。该算法使玩家更倾向于保持高数值方块在棋盘上，与传统玩法形成差异化体验。源代码见 `lib/features/game_2048/providers/game_provider.dart`。

### 2. 独创音效引擎：解析式 Chirp 相位公式

本软件不依赖任何外部预制音频资源，自研音效引擎通过解析式 Chirp 相位公式实时合成 PCM 波形：

```text
phase(t) = 2π · ∫(f_start + (f_end - f_start) · t / T) dt
signal(t) = amp(t) · sin(phase(t))
```

根据合并数值所在档位（共 4 档）动态调整起止频率、扫频时长、四阶段包络（Attack/Decay/Sustain/Release），并耦合触觉反馈强度。该方案保证零相位突变、零杂音、零外部资源占用。源代码见 `lib/features/audio/services/sfx_service.dart`。

### 3. 独创 TTS 调度架构：双轨并行 + Session 哨兵

本软件 TTS 朗读采用申请人自研的双轨并行生产者-消费者模型：

- **预加载轨道**：提前 1-2 句缓冲下一段音频
- **播放轨道**：同步消费当前句子，与预加载严格隔离
- **Session 哨兵**：每次音色切换/章节跳转时 `_session` 计数器递增，所有旧会话残留音频在解码前被识别并丢弃

该机制解决了主流 TTS 实现普遍存在的"切音色后旧音频乱序播放"问题。源代码见 `lib/features/audio/providers/tts_audio_notifier.dart`。

### 4. 独创算法环境音：Voss-McCartney 粉噪声合成

本软件环境氛围音采用 Voss-McCartney 算法实时合成粉噪声（1/f 噪声），叠加 60Hz 工频嗡鸣模拟"赛博朋克"美学，提供 wuxia / warm 两种风格曲线，全部在客户端实时生成，零网络流量、零外部资源依赖。源代码见 `lib/features/audio/services/ambient_service.dart`。

### 5. 独创网络协议：分离下载契约

本软件 TTS 客户端-服务端通信采用申请人独立设计的"分离下载"协议：

- 客户端先 POST 文本至 Go 服务端，获取 JSON 响应（含 OSS 音频 CDN URL）
- 客户端再 GET 该 URL 直接从 CDN 下载音频字节流

该协议避免了 POST 响应体直接传输大体积音频流的弊端，分离了"业务逻辑"与"音频载荷"，并能复用 OSS/CDN 的边缘加速能力。源代码见 `server/handler_tts.go` 与 `lib/features/audio/services/tts_audio_downloader.dart`。

### 6. 独创交互设计：阅读/听读/游戏三态联动

本软件的阅读器、TTS 朗读、2048 游戏三大子系统通过 ReaderProvider 中央状态机进行联动：

- 朗读时实时高亮当前句、自动滚屏跟随
- 玩 2048 时背景音乐与朗读音轨智能淡入淡出
- 进入游戏不中断朗读、退出游戏自动恢复

该多模态联动机制为申请人独立设计与实现。源代码见 `lib/features/reader/providers/reader_provider.dart`。

### 7. 独创视觉资产：赛博朋克吉祥物 XIAOYO

软件主界面采用申请人原创设计的 2048 棋盘吉祥物 XIAOYO（基于 Rive 动画引擎），具备眼球追踪滑动方向、身体跳跃、表情变化、头部倾斜、棋盘晃动、独立眨眼六层动画控制器，所有动画曲线由申请人独立调试。源代码见 `lib/features/game_2048/presentation/widgets/board_mascot.dart`。

## 三、与同类软件的本质差异

主流 2048 游戏只有计分与合并功能，主流听书软件只有 TTS 朗读功能。本软件首创"小说沉浸阅读 + 2048 益智游戏 + 自研物理音效 + 算法合成环境音"四位一体的产品形态，并通过赛博朋克统一视觉语言把它们整合为一个有机整体，在国内外应用市场具有显著独创性。
