# 文档目录 (docs)

阅游项目文档集中目录。按主题分子目录，根级文件为跨领域总览文档。

## 子目录

| 目录 | 用途 |
| :--- | :--- |
| `historical/` | 已废弃 / 已被替代的历史文档与实验残留（只读溯源） |
| `product/` | 产品文档：商店上架文案、手机原型、IP-0 资产清单等 |
| `performance/` | 性能基线、帧统计与真机采集工具说明 |
| `testing/` | 测试与 CI 相关文档 |
| `ui-demo/` | UI 演示素材 |
| `copyright/` | 版权登记材料（源程序、原创性说明、鉴定材料等） |

## 根级文档

| 文件 | 内容 |
| :--- | :--- |
| `TTS_FLOW.md` | 当前 TTS 音频流状态机架构流程图 |
| `yueyouflowchart.md` | 应用整体流程图（启动引导、服务初始化、功能模块） |

## 规则

- 新增文档按主题放入对应子目录；无合适子目录的总览文档放在根级并更新本表。
- 历史 / 已废弃文档移入 `historical/`，规则见 `historical/README.md`。
